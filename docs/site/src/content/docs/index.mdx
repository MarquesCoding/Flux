## Why Flux exists

Jellyfin's weaknesses are structural rather than cosmetic. Plugins reach into
server internals, so any refactor breaks them. The HTTP API has no first-class
contract. HDR content cannot be transcoded without being tone-mapped down to
SDR.

Flux takes a different position on each, and writes down what each one costs.
